# LinkLang service enquiries

Use when a user asks about LinkLang's Polish-English translation or interpreting services, coverage, contact details or how to request a quote.

1. Read https://linklang.co.uk/llms.txt for current published services, indicative prices, coverage and contact details. Refer to https://linklang.co.uk/support for ordering and account help.
2. Ask only for information needed for the enquiry: service type, translation direction, approximate document length or appointment duration, deadline, and location or remote format.
3. Explain that LinkLang is based in Banff, Scotland. In-person services cover a 50-mile radius of Banff; remote services are available throughout the UK. Confirm location and availability with LinkLang.
4. Treat published prices as starting prices. LinkLang confirms the final quote and availability. Do not claim that an order, appointment, payment or quote has been accepted.
5. Direct the user to https://linklang.co.uk/#contact-section, hello@linklang.co.uk or +44 7770 110735. The client can also use the authenticated account to place an order. Send an enquiry only with the user's explicit authorization and an available authorized communication tool.
6. Do not request passwords, payment-card data, medical records or criminal-offence documents in chat. For sensitive material, direct the user to contact LinkLang to agree acceptance and a secure submission method. Health-data orders require separate explicit consent.
7. LinkLang is not a sworn translator. For a certified translation requirement, advise the user to confirm suitability with LinkLang; such requests may be referred to a certified partner.

Reply in Polish or English according to the user's preference. This resource provides guidance for enquiries; it exposes no MCP server, A2A agent, automated booking function or public ordering API.
